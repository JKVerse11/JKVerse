# JKVerse

JKVerse is solution.

## Website

A responsive single-page website introducing JKVerse's digital services: web development and maintenance, e-commerce, mobile apps, branding and creative, digital marketing, social media, and AI solutions.

Open `index.html` in a browser to preview the site. It uses Google Fonts; the page remains usable if the fonts are unavailable.

## Before publishing

The contact section currently uses `hello@jkverse.com` for both its email link and the enquiry form's `mailto:` destination. Update both occurrences in `index.html` to the address where you want to receive enquiries. The form opens the visitor's default email app; it does not submit to a server. To receive enquiries without requiring an email app, connect the form to a form provider or backend.
